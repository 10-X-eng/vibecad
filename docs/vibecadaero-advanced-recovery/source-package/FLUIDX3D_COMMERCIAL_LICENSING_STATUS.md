# FluidX3D Commercial Licensing Status

**Reviewed:** 2026-08-19 / 2026-08-20 UTC boundary  
**Source pin:** `ProjectPhysX/FluidX3D@8986874e626e0aebd317ab16c420b39e30dfa273`

This file is informational and concerns **FluidX3D only**.

The current public FluidX3D license does not permit commercial use of FluidX3D unless explicit permission is granted by the copyright owner. The official README says a second commercial license may be offered later and asks interested users to contact the author.

At this reconciliation point the official repository does **not** publish:

- a standard commercial agreement;
- a standard commercial price;
- a standard commercial EULA;
- a standard redistribution grant;
- a required “external installation” architecture for commercially permitted use.

Therefore VibeCAD must not invent those terms. If commercial FluidX3D rights are desired, the actual permission/license granted by the FluidX3D copyright owner controls the arrangement.

This status does not make VibeCAD or VibeCADAero non-commercial and does not relicense CAD designs created with VibeCAD.
